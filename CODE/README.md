# Code

This folder contains the Python code used for the lung cancer prediction project.

The code covers data preprocessing, exploratory data analysis, statistical testing, feature analysis, machine learning model development, ROC curve analysis, and model evaluation.

The following models were implemented and compared:

- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- XGBoost
- Artificial Neural Network (ANN)
- Naïve Bayes
